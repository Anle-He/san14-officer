# 立绘素材处理与导入

## 确认原图与目标

查看用户提供的已有图片，按本次请求完成裁切、缩放、格式转换、抠图、背景处理或导入准备。保留原图，在副本上处理。

需要导入时，根据目标工具说明或成功样本确认尺寸、格式、位深与透明度要求，并区分大立绘、小头像等用途。使用官方 CG 追加工具时，参考 [CG追加ツールの解説](https://wikiwiki.jp/sangokushi14/CG追加ツールの解説)。

## 格式与背景处理

尺寸、格式和通道处理使用文件处理工具；抠图和背景处理使用当前可用的图像编辑工具，按其要求执行。

需要透明背景时，通过 Alpha 保留主体及边缘过渡；需要实色或图片背景时，用处理好的主体合成。

## Alpha 与边缘检查

重新读取输出文件，确认尺寸、格式和 Alpha 符合目标要求。在深浅背景上预览透明素材，检查主体完整性、细部边缘、半透明过渡和背景残留。

## 导入兼容性与交付

按目标工具选择编码。出现读取或透明度异常时，针对文件结构、通道和图像方向排查。

交付所需文件和效果预览，标明文件用途、尺寸与格式，按需打包。说明实际完成的文件检查；需要导入时，说明目标工具内的验证情况。
